Voxel Coding

Voxel Coding is a learning environment designed to help people develop computational and spatial thinking. Learners are given the option to play a voxel-style game using Blockly to build their environment. The environment is used as a creative playground for learners that want to experiment with automations and geometry in an exploratory 3D space.

YaBRI - Yet another Browser REPL Interface

YaBRI is an interactive JavaScript Read-Eval-Print Loop (REPL) component designed as a reusable and embeddable web component. It provides a powerful and isolated environment for executing JavaScript code directly within web applications.
